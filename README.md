# R for Marine Science

This repo contains my R work for the R for Marine Science module in MB5370.

## About

The workshops focused on working with marine and ecological data in R. I worked through data cleaning, visualisation, statistics and spatial analysis.

## Workshops

### Workshop 1
Basic data handling, summaries and visualisation in R.

### Workshop 2
Cleaning and organising marine datasets and working with joins.

### Workshop 3
Statistical analysis and comparing groups using R.

### Workshop 4
Working with spatial data using `sf`, `terra` and `tmap`.

## Repository structure

`code/` contains the workshop scripts and rendered workshop pages.

`data/` contains the datasets used throughout the workshops.

## Data

The datasets used in this repo were provided through the MB5370 R for Marine Science workshops.
